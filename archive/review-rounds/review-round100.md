## 教训
1. **里程碑轮做「观察项会计核算」**：100 轮节点不找新缺陷而是清算账目——近 15 轮观察项逐项评估「实际影响 vs 修复成本」，O92-02/O98-02/O90-01 均未达清零修复的 ROI 阈值。**观察项管理不仅是挂账，更要在里程碑节点系统性清理：能归档的归档、能维持的明确维持理由、绝不无限期堆叠**。
2. **「残余出现→回落→再现」完整周期的低频口径**：七轮 26 跑 4 单例 ~15%——抖动基线的定级从「单轮样本」升级为「多轮统计口径」，残余的周期性波动本身就是宿主环境函数的指纹。
3. **身份防线矩阵十五轮零新裸露写点**：连续十五轮清单化复核，防线缺口类缺陷的发现面已被系统性收窄至几乎为零——矩阵作为持续防御结构的价值在 100 轮里程碑得到完整验证。
4. **前端 46 轮零严重级 + build 哈希逐字节一致**：web/ 自 f08937e 后零代码提交的「零漂移」状态被每轮 git log + build 哈希双重实证——连续观察轮的价值不是找新缺陷，而是确认「稳定性」本身。
