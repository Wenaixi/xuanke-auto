## 教训
1. **「八连零复现 → 低频残余」的基线降级是测试健壮性信号而非产品缺陷**：O94-01 的残余样本全集中冷启动窗口、定向复测零复现——与 R80-R93 归因链（夹具共享全局态 + Windows 回环冷启动）完全一致，无产品逻辑新触发面。「零残余」目标从「连续三轮」到「八连零复现」再到「低频残余」，证明残余面随宿主环境波动——**抖动观察的定级取决于「是否有产品触发面」而非「样本出现频率」**，CI `-p 1` + 失败重跑口径持续吸收。
2. **F93-01 修复的残余面管理**：审查代理明确「裸按钮 10+ 处 + ring 参数未统一均为 OBSERVE-93-01 已声明延续，不重复立条」——**已声明的残余面不重复立观察项**，避免观察项膨胀。
3. **连续第四十轮前端零严重级**：M-1 逐字符比对 + 换方向扫查 + 前提复核 + 三组断言纪律的稳定产出——40 轮无严重级不等于无价值，每轮仍扫出新角度（无障碍横复核/视觉反馈/并发边界）并复核历史修复。 
4. **身份防线矩阵第十轮**：16 项矩阵作为持续复核清单已连续九轮零新裸露写点——「修复带出的清点」沉淀成防御结构后，防线缺口类缺陷的发现面被系统性收窄。
