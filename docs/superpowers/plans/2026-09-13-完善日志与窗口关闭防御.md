# 完善日志系统与窗口关闭防御 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完善服务端日志系统（探测/窗口状态/重登/登录失败全链路可见），并加固选课窗口关闭后的行为防御，让"为什么课程为空 / 为什么登录失败"这类问题一眼可查。

**Architecture:** 在调度器探测、窗口状态判定、自动重登、登录失败四条路径上补齐日志；探测与窗口状态增加结构化日志并同步写入 `task_log`；窗口关闭后课程接口直接返回空快照 + 状态标记（当前已实现解析层，需在调度器暴露"窗口已关闭"状态）。

**Tech Stack:** Go 标准库 `log` + `modernc.org/sqlite`（task_log 表），前端 `/state` SSE 复用。

**Spec:** 依据本会话实测结论（[根因分析](./2026-09-13-根因分析.md)）：
- 平台接口鉴权以 Cookie 头 `zd_edu_cookie` 为准，缺失即返回"您未登录"——`doRequest` 已修复补全双通道。
- 验证码识别结果需净化（只保留字母数字，3~5 位）——`normalizeCaptchaText` 已实现。
- 内置 ddddocr 引擎与平台验证码风格不匹配，默认引擎应切回 Vision——已修复。
- 选课窗口关闭后 `findElectivesData` 返回 code:0 空 publishes，属正常业务状态，不应误报错误。

## Global Constraints

- 注释与日志文案一律简体中文，不用 emoji、不写 AI 味。
- 每次小步完成立即 `git commit`（不 push 远程，仅本地仓库）。
- 所有日志不打印明文密码/token 完整值（token 只打印前 6~8 位）。
- 修改只触碰需要改的文件，不重构相邻代码。
