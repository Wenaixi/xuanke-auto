# 精制微圆角现代暗黑风格与前后端解耦 UI 重构设计规范

## 1. 概述与设计理念

本文档定义了至道选课自动化系统前端界面的精制微圆角（Refined Micro-Radius）现代化重构规范。

在先前的重构中，系统探索了瑞士国际主义与黑白单色风格，但因采用绝对零圆角（Zero-Radius）与强行切平一切边角的全局规则（`border-radius: 0 !important`），导致界面在视觉与心理体验上过于锐利割手、冰冷生硬。同时，原架构将前端产物强行通过 `go:embed` 打包进单一 Go 二进制服务中，破坏了现代 Web 工程的独立演进能力与极速热重载（HMR）体验。

本次重构旨在：
1. **重塑视觉亲和力与质感**：告别刀锋般的刺手直角，引入 **6px-8px 精制微圆角梯度系统**。在维持纯净黑白冷色调、等宽排版（tabular-nums）与工业级严谨克制感的同时，赋予界面温润、舒适、高耐看度的人性化现代科技美学；
2. **前后端架构彻底解耦**：移除单文件/单二进制强行捆绑，确立 Go 核心服务（`:8080`）与 React + Vite 前端（`:5173`）完全独立的现代解耦工程范式。

## 2. 架构设计：前后端解耦独立规范

### 2.1 职责边界清晰化
- **Go 抢课调度后端（backend/）**：
  - 技术栈：Go 标准库 `net/http`（Go 1.22+ 原生路由）+ `modernc.org/sqlite`（纯 Go 免 CGO）。
  - 核心职责：会话持久化、RSA 加密、验证码识别、抢课调度引擎、REST API 与 SSE 实时事件流推送。
  - 运行机制：独立在 `http://localhost:8080` 启动，专注于高并发与毫秒级抢课逻辑，不再负责内嵌打包或托管前端 HTML/JS 静态资产。
- **React 现代前端（web/）**：
  - 技术栈：React 18 + Vite + TypeScript + Radix UI 原语 + Tailwind CSS。
  - 核心职责：状态看板、实时脉搏倒计时、课程搜索过滤、多选课目标管理、抢课日志流展示。
  - 运行机制：独立在 `http://localhost:5173` 启动开发服务器，通过 Vite 开发代理（Proxy）将 `/api` 和 `/events` 自动透明转发至 Go 后端。生产构建输出独立静态资产包，与后端完全解耦。

## 3. 精制微圆角视觉系统规范（Visual Design System）

### 3.1 调色板与材质层次（Refined Dark Palette）
界面维持纯粹、深邃的高级暗黑单色阶，杜绝杂乱的高饱和度色彩干扰：
- **背景层（Surfaces）**：
  - 画布主背景（Canvas）：`#09090b`（深邃底黑）
  - 主卡片容器（Surface）：`#121215`（略带微亮的碳黑表面，形成柔和对比）
  - 次级弱化表面（Surface Soft）：`#18181b`（用于表头、嵌套输入区、次级条目）
- **边框与高光层（Borders & Highlights）**：
  - 默认温润发丝线（Border）：`#27272a`（冷灰细线，带微柔漫反射）
  - 悬浮/聚焦微光线（Border Hover / Focus）：`#3f3f46`（细腻提亮）
  - 高亮纯白线（Border Invert）：`#fafafa`（用于焦点选中与关键状态）
- **文本与前景层（Typography & Foreground）**：
  - 主标题与高对比重点（Foreground）：`#fafafa`（纯净亮白）
  - 次级说明信息（Muted）：`#a1a1aa`（典雅浅灰）
  - 弱化辅助时间戳（Dim）：`#71717a`（柔和深灰）

### 3.2 严格微圆角梯度体系（Micro-Radius Scale）
彻底从 `global.css` 中删除 `* { border-radius: 0 !important; }`，构建以下精准、严密的四级圆角体系：
- **`sm` (4px / 0.25rem)**：
  - 适用场景：`Badge` 状态微标、Tag 标签、迷你角标。
  - 特性：紧凑精致，消除文字外围的小毛刺感。
- **`md` (6px / 0.375rem)**：
  - 适用场景：`Button` 按钮、`Input` 输入框、`Tabs` 切换滑块。
  - 特性：交互触控黄金曲率，按压感扎实温润，手感极佳。
- **`lg` (8px / 0.5rem)**：
  - 适用场景：`Card` 容器卡片、`Table` 外层容器、`Progress` 进度条轨道。
  - 特性：视网膜级柔和边缘，构筑界面模块的呼吸感。
- **`xl` (12px / 0.75rem)**：
  - 适用场景：`Dialog` 沉浸式模态弹窗、Popover 浮层。
  - 特性：浮层优雅内敛，带来顶级现代桌面的悬浮包裹感。

### 3.3 阴影与景深微光（Subtle Ambient Lighting）
为了消除原本扁平黑白界面的压迫感，引入两组轻量 CSS 阴影：
- `shadow-sm`：`0 1px 2px 0 rgba(0, 0, 0, 0.4)`，用于按钮与小型卡片。
- `shadow-dialog`：`0 16px 40px -12px rgba(0, 0, 0, 0.8), 0 0 0 1px rgba(255, 255, 255, 0.08)`，用于弹窗，提供微微发光的轻盈浮空感。

### 3.4 数据排版与文字规范
- 倒计时数值、已报/计划人数容量统计全面启用等宽数字（`font-variant-numeric: tabular-nums`），防止数字跳动导致的界面抖动。
- 英文采用 Inter/JetBrains Mono，中文采用 PingFang SC/Microsoft YaHei。

## 4. 组件库重构清单（web/src/components/ui/）

所有 UI 组件均基于微圆角规范全面重构：

| 组件文件 | 改造前（零圆角） | 改造后（精制微圆角） | 交互与视觉重点 |
| :--- | :--- | :--- | :--- |
| `global.css` | `* { border-radius: 0 !important; }` | 移除强制直角，配置 `--radius` CSS 变量 | 允许组件自由应用 Tailwind 圆角工具类 |
| `Button.tsx` | 直角，`rounded-none` | `rounded-md` (6px) | 悬停反色平滑过渡，保持 1px 发丝边框 |
| `Input.tsx` | 直角，`rounded-none` | `rounded-md` (6px) | 聚焦微光白边聚焦，圆润舒适内衬 |
| `Badge.tsx` | 直角，`rounded-none` | `rounded-sm` (4px) | 紧凑等宽小标签，消除硬切边缘 |
| `Card.tsx` | 直角，`rounded-none` | `rounded-lg` (8px) | 柔和模块边缘，悬停边框平滑提亮 |
| `Progress.tsx`| 直角条形轨道 | `rounded-md` (6px) 轨道与内部填充 | 饱满流线型几何进度感 |
| `Dialog.tsx` | 纯直角模态框 | `rounded-xl` (12px) 浮层容器 | 带有微光白边外圈与深邃漫反射投影 |
| `Tabs.tsx` | 纯直角分段滑块 | `rounded-md` (6px) 滑块与容器 | 滑块切换柔和自适应 |
| `Table.tsx` | 直角外边框网格 | `rounded-lg` (8px) 容器，首尾行平滑过渡 | 顶角底角温润包容，数据整齐对齐 |

## 5. 三大核心页面重构蓝图

### 5.1 登录页（Login.tsx）
- **构图与美学**：居中卡片式画廊布局，容器应用 8px 微圆角，悬浮于纯黑深邃背景之上。
- **表单体验**：账号与密码输入框采用 6px 微圆角与发丝边框，带密码眼睛切换；登录按钮具有 6px 微圆角与高亮反色动画。
- **状态徽章**：顶部的 RSA-1024 会话状态与底部系统提示采用 4px 微圆角标签，整体温润内敛。

### 5.2 仪表盘看板（Dashboard.tsx）
- **Bento Grid 模块化微圆角**：
  - 核心抢课倒计时巨幕卡片：8px 微圆角，巨幅等宽数字（天/时/分/秒）脉搏律动。
  - 状态指标卡片：8px 微圆角，展示认证状态、调度器开关与抢课窗口周期。
  - 3 门目标课程监控卡片：8px 微圆角，支持快速查看实时人数进度条。
- **UNIX 极客实时日志流**：
  - 8px 微圆角深黑终端窗口，保留极客代码质感与闪烁指示灯，同时去除生硬的尖锐角。

### 5.3 选课选修大厅（Select.tsx）
- **课程矩阵卡片**：
  - 8px 微圆角卡片，内嵌 6px 微圆角名额进度条（如 29/29 人满额与剩余名额显示）。
  - 快速报名/退选按钮应用 6px 微圆角，hover 高亮反色。
- **工具栏与筛选器**：
  - 模糊搜索框与状态过滤下拉按钮统一为 6px 微圆角。
- **画册级课程详情弹窗**：
  - 基于 Radix Dialog，主体赋予 12px 优雅微圆角与 `shadow-dialog` 微光悬浮阴影。
  - 内部详细参数表格采用 8px 圆角嵌入，彻底解决弹窗直角割裂视线的问题。

## 6. 验证与测试策略

1. **类型检查与构建验证**：
   - 执行 `npm run build`，确保 TypeScript 类型无报错，CSS 编译无冲突。
2. **样式隔离与圆角统一性验证**：
   - 检查所有页面中的微圆角阶梯是否严格对应：Badge(4px)、Button/Input(6px)、Card/Table(8px)、Dialog(12px)。
   - 确保没有残留的 `rounded-none` 或 `!important` 产生视觉违和。
3. **前后端解耦联调验证**：
   - 验证 Vite 开发服务器在 `:5173` 独立运行，反向代理 `/api` 正常与 Go 后端通信。
